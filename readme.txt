Connect Polylang for Divi – Easily add a customizable language switcher to your Divi pages using Polylang.

== Description ==

**Connect Polylang for Divi** is a WordPress plugin that helps you add a language switcher to your website using the Divi Builder. This plugin connects the Polylang multilingual plugin with the Divi theme, making it easier to build a multilingual website.

Normally, **Polylang** and **Divi** don't work smoothly together when it comes to showing a language switcher inside your pages. You need to create different WordPress menus for each language, and then assign a menu to each language page manually, which is a time-consuming and tiring task. That's where **Connect Polylang for Divi** helps.

With this plugin, you can place a customizable language switcher on your Divi pages using a dedicated Divi module.

### Key Features
* **Support for Divi Module:** This plugin works directly inside the Divi builder. Simply drag and drop the language switcher module anywhere on your page, just like other Divi elements. No need to write any code or use external widgets. 

* **Layout Options:** The plugin offers three layout styles, Dropdown, Horizontal & Vertical. Choose how you want the language switcher to appear on your website.

* **Customize Switcher Elements:** Easily customize the appearance of the language switcher elements by enabling or disabling the following:
* **Language Flag:**  Show a small flag icon next to each language (e.g., 🇺🇸).
* **Language Name:** Display the full language name (e.g., English, Spanish).
* **Language Code:** Show language short codes like EN, FR, DE, etc.
* **Hide Current Language:** Hide the language that is currently active.
* **Hide Untranslated Languages:** Hide specific languages if the current page has no translated version available in that language.


* **Frontend Display Preview:** Preview the changes from the frontend and make sure everything appears correctly before publishing.
* **Fully Compatible with Polylang Free and Pro.**
* **User-friendly.**
* **Fully Responsive.**

### How to Add the Language Switcher
* Go to your WordPress Dashboard.
* Open the page, post, header, or footer where you want to add the language switcher using the Divi Builder or Theme Builder.
* Drag and drop the Language Switcher module to your desired section (body, footer, header, sidebar, etc.).
* Customize its layout and visibility settings according to your preferences.

== Frequently Asked Questions ==

= Where can I place the language switcher on my site? =
You can place the language switcher anywhere inside a Divi layout, including: Pages, Posts, Headers, Footers, & Sidebars.


= Do I need to create separate menus for each language? =
No, unlike the default Polylang setup, you don't need to manually create or assign separate menus for each language.


= What layout styles are available for the language switcher? =
You can choose from 3 layout styles: Dropdown, Horizontal, and Vertical.

=  Is this plugin compatible with Polylang Pro? =
Yes. It works with both the free and Pro versions of Polylang.
